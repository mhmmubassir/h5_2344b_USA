# Standing HA phenotypic breadth shapes H5N1 cross-host potential

Repository for the processed data products, analysis scripts, figure-generation workflows, and supplementary materials associated with:

**Mubassir et al. (2026)**
*Standing HA phenotypic breadth shapes H5N1 cross-host potential*

---

## Summary

This repository contains computational materials supporting a population-scale analysis of hemagglutinin (HA) phenotypic variation in U.S. H5N1 clade 2.3.4.4b viruses. The study links naturally circulating HA sequence variation to predicted protein phenotypes, structural features, stability estimates, receptor-binding-site geometry, molecular dynamics outputs, and receptor-engagement metrics.

The central goal is to examine how predicted HA phenotypic breadth emerges, is pruned, and changes during avian and cattle-associated H5N1 circulation.

---

## Repository contents

The repository includes:

* processed phenotype tables
* figure source data
* main and supplementary figure panels
* scripts for analysis and visualization
* supplementary data files
* GISAID acknowledgement materials
* pipeline components for structural and phenotype analyses

Large raw intermediate files, database-restricted sequence inputs, and high-volume simulation outputs are not fully distributed here. Processed derivatives needed to reproduce manuscript-level figures and summaries are provided where possible.

## Key analyses

This project includes workflows for:

* HA sequence curation and variant definition
* time-scaled HA phylogenetic analysis
* sequence-derived phenotype calculation
* AlphaFold/Rosetta-based structural and stability analysis
* receptor-binding-site geometry analysis
* molecular dynamics and MM/GBSA-based receptor interaction analysis
* figure and supplementary figure generation

Genome sequences and metadata were accessed through GISAID EpiFlu. A complete GISAID acknowledgement table for the sequences used in this study is provided in this repository.

Processed data products and figure source files are included to support interpretation and reproduction of the manuscript figures and supplementary analyses.
